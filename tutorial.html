Core components

Explore lucUI's reusable components.

Each card below explains a component, shows how it fits into real interface flows, and helps you choose the right element for the job.

Open the docs

Cards

Cards group related content and create a clean visual surface for panels, stories, and features. Use them for onboarding, tooltips, and content summaries.

Buttons

Buttons are the action points in your interface. Use primary buttons for main calls to action, and secondary buttons for less prominent controls.

Tabs

Tabs let you organize related content into clear, switchable panels. Use them when users need to compare sections without leaving the current view.

Modals

Modals focus attention on a single task or message while keeping the rest of the page in view. Use them for confirmations, details, or short forms.

Toasts

Toasts communicate short updates with minimal disruption. Use them for save confirmations, alerts, or subtle status messages.

Progress

Progress bars help users understand status and completion at a glance. Use them for uploads, onboarding steps, and task progress.
