What is glass morphism?
Glass morphism is a design trend using frosted-glass effects — translucent surfaces, backdrop blur, and subtle borders that create depth and layering without heavy drop shadows.
Does lucUI require a build step?
No. lucUI is plain CSS with CSS variables. Drop a single <link> tag into your HTML and you're done. No Sass, no PostCSS, no bundler needed.
How do I enable light mode?
Add data-theme="light" to your <html> or <body> element. lucUI also respects the OS prefers-color-scheme media query automatically.
